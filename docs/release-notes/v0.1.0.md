最初の公開ビルド。GitHub Actions が各 OS の実ランナーでビルドしたポータブル版（インストーラー無し）。

| ファイル | 中身 |
| --- | --- |
| `HitokoePet-windows.zip` | `bin/*.exe` + `resources/`。展開してそのまま起動 |
| `HitokoePet-macos.zip` | `HitokoePet.app`（ad-hoc 署名のみ）。初回は右クリック > 開く |
| `HitokoePet-linux.zip` | `bin/` + `share/`（GTK4 が必要） |

## 確認状況

- 実機で確認したのは Windows のみ（透過・つまみ・多セッション集約・吹き出しタップ・状態連動ボイス・トレイ）。
- macOS / Linux はビルドとテストが CI で通ることだけを確認している。
- 口パクは未実装。アイドル時 CPU の削減は確認できていない（README の「計測」）。

## 使い方

1. ペット素材を `~/.petdex/pets/<id>/`（`pet.json` + `spritesheet.webp`）に置く。Codex 用のペットもそのまま使える。
2. 設定画面（右クリック > Open Settings）の Agents から Claude Code のフックを登録する。
3. 状態連動ボイスはボイス素材を同梱しているペット（`iroha`）を選んでいるときだけ鳴る。

署名していないので、Windows では SmartScreen、macOS では Gatekeeper の確認が出る。
